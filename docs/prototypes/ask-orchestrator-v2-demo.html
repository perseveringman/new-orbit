最终想做的不是“更会聊天”，而是一个 Ask Runtime。

这个原型把随处问拆成 RunController、Intent Router、Context Orchestrator、Runtime/Tool Loop、Synthesis Scheduler 和 Semantic Answer Layer。 它的关键体验目标是：用户一发送就有真实状态，简单问题不进重链路，复杂问题也不会用慢上下文阻塞首 token。

RunController 创建 run、写 checkpoint、发 phase event、负责取消和恢复。
Context Orchestrator Fast、Retrieval、Slow 三条 lane，按预算和 freshness 降级。
Semantic Answer 先回答用户意图，再引用证据，隐藏 PMIL 内部术语。
Intent Router direct、vault QA、connector inventory、research、action 分流。
Tool Runtime 只暴露本场景需要的工具，串行或并行按 policy 执行。
Synthesis Scheduler 慢总结和外部会话扫描后台跑，以 artifact 形式补入。
